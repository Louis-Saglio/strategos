# Game description — 0 A.D. 0.28.0

Reference documentation of the game for agents developing the bot. Everything
here is grounded in the 0 A.D. source reference (0.28.0 — the version the
harness runs; see `AGENTS.md`), not in general knowledge of 0 A.D.:
entity data was extracted from the simulation templates by the versioned
scripts in `tools/`, and the mechanics files were written by reading the
simulation source, with inline `path:line` citations relative to its root. If
a statement looks
wrong, trust the source and fix the doc.

## Layout

- [`mechanics/`](mechanics/) — **how the game works**, one file per
  mechanic: resources/gathering, construction, training queues, population,
  combat/damage formula, capture, promotion/XP, territory, technologies and
  the modification pipeline, auras, vision/fog of war, garrisoning, healing,
  trade, loot, victory conditions, orders and simulation time. Start here to
  understand a rule of the game.
- [`generic/`](generic/) — **entity data** for units, buildings, technologies
  and auras shared by several civilisations (`units/`, `buildings/`,
  `technologies/`, `auras/`, one file per entity). Each file gives the merged
  template stats, per-civ variants, and which civilisations can train/build/
  research it.
- [`athen/`](athen/), [`brit/`](brit/), [`cart/`](cart/), [`gaul/`](gaul/),
  [`germ/`](germ/), [`han/`](han/), [`iber/`](iber/), [`kush/`](kush/),
  [`mace/`](mace/), [`maur/`](maur/), [`pers/`](pers/), [`ptol/`](ptol/),
  [`rome/`](rome/), [`sele/`](sele/), [`spart/`](spart/) — one folder per
  civilisation (all 15 playable civs of 0.28.0), named by its civ code,
  holding both halves of the civ's description:
  - the **per-entity files** for entities exclusive to that civ (`units/`,
    `buildings/`, `technologies/`, `auras/` — one file per entity, same
    format as `generic/`);
  - the **civ delta** (`civ.md`): everything that differs between a civ and
    a generic civilisation — civ/team bonuses, starting entities, wall sets,
    building and unit rosters, the tech tree, auras and stat modifiers. The
    one-page synthesis of the per-entity files; start here for the civ-level
    picture.
- [`biomes/`](biomes/) — **map biomes**, one file per biome (the 10 generic
  `generic/*` biomes usable on every random map, plus the 9 map-specific
  sub-biomes). What each biome changes for the bot (tree density and wood per
  tree, huntable animals, fruit, fish) and what it does not (heights,
  passability, mine amounts), with the shared mechanics in
  [`biomes/README.md`](biomes/README.md).

Every unit and building file opens with a **Guide** section: what the entity
is for and its role in the game, from a bot's perspective (resource scarcity
framing: food/wood are abundant, stone/metal are premium).


## Regenerating the entity docs

The `<civ>/` entity files (`units/`, `buildings/`, `technologies/`,
`auras/` and their `README.md` indexes) are generated by
`tools/gamedata/gen_civ.py` — see `tools/README.md`. Regeneration rewrites
the generated sections and keeps each file's handwritten **Guide**
paragraph; a new file gets a `TODO` Guide to write by hand. The `generic/`
files have no generator in this repository. The `mechanics/` files, the
`biomes/` files and every `<civ>/civ.md` are fully handwritten and never
generated.
