# Gaul-specific auras of 0 A.D. 0.28.0

One file per aura that **only the gauls** can have (single-civ auras of the `generic/auras/` analysis): the gaul teambonus (the `special/players/gaul.xml` player aura), hero auras and auras attached to gaul-unique entities. Shared auras are documented in `docs/game_description/generic/auras/`.
